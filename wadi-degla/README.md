# Wadi Degla Developments

Live: https://wadidegladevelopments.com/

Corporate website for Wadi Degla Developments, a real estate developer in Egypt, showing its projects and properties.

## My role

WordPress developer. I built the custom theme from the provided designs and handled the backend features.

## What I built

- Projects and properties as custom post types, managed with ACF
- AJAX filtering and search for listings
- Referral coupon system that generates a QR code and emails it to the user, used in marketing campaigns
- Image galleries tuned to load fast despite large photos
- SEO setup with Yoast and forms with WPForms

## Stack

WordPress, PHP, custom theme, ACF, AJAX, JavaScript, Yoast SEO, WPForms
