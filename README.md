## How I build them

All of them use custom themes written from scratch from the client's designs, with no page builders. I set up the content so the client can edit texts, images and lists from the admin without breaking the layout. For most sites I used a Theme Options page and CMB2 fields. For Wadi Degla I used ACF.

**Stack:** WordPress, PHP, CMB2, ACF, JavaScript, AJAX, Bootstrap

I'm a full-stack developer (Angular / .NET). Check my other repos for my ERP and enterprise work.
