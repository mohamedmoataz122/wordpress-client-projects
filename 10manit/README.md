# 10manit

Live: https://10manit.com/

Landing page for 10MAN, a Dubai-based company that implements Odoo ERP. The goal of the site is simple: explain what they do and get visitors to request a consultation.

## My role

WordPress developer. I built the theme from the provided designs.

## What I built

- One-page layout: hero with a consultation form, Odoo modules section, "Why 10MAN", implementation steps, stats and footer
- Contact form that sends over AJAX and shows the result without reloading the page
- SMTP settings (Microsoft 365) in the theme options, so the client doesn't need a separate mail plugin
- All section texts and contact details editable from a Theme Options page built with CMB2
- Small scroll animations and the lines connecting the module cards, written in plain JavaScript

## Stack

WordPress, PHP, custom theme, CMB2, Bootstrap 5, AJAX, JavaScript
