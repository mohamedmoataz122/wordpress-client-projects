# Beyond Van Gogh Egypt

Live: https://beyondvangoghegypt.com/

Website for the Egyptian edition of Beyond Van Gogh (and later Beyond Monet), the immersive art exhibition held at District 5 in New Cairo. It covers the exhibition info, FAQs and ticket pre-registration.

## My role

WordPress developer. I built the theme from the provided designs.

## What I built

- Home page with a video hero, exhibit info (dates, location, map), FAQs and a gallery
- Theme Options with CMB2 so the marketing team could change dates, texts, images and links on their own during the campaign
- FAQs as a custom post type, grouped by topic and ordered from the admin
- Pre-registration form that sends visitor data to the external ticketing system's API through the WordPress backend
- Facebook Pixel event on successful registration
- Policy page template and a mobile-friendly header and menu

## Stack

WordPress, PHP, custom theme, CMB2, custom post types, AJAX, Bootstrap 5, JavaScript
